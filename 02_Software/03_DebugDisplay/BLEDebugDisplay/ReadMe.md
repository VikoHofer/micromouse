# DebugDisplay

Connects to the debugger on the micromouse and outputs debug messages.

## Usage

> Requirements: C# .Net 8.0+ SDK

### Build

Open a shell in the current directory. Build the tool with `dotnet build` (any platform) or use `make build`.

### Run

Open a shell in the current directory. After the tool is built, run it with `dotnet run` (any platform) or use `make run`.

## Simulator

For the usage with the micro mouse simulator (MMS), refer to `Simulator.md`.
