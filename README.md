# Micromouse

A Micromouse is a compact robot that combines electronics, mechanics, embedded software, control engineering, and sensor technology in a small, integrated system.

Its purpose is to autonomously explore an unknown maze, determine the shortest or fastest possible route, and subsequently complete that route reliably at high speed.

The challenge is not merely to make the robot move, but to enable it to perceive its surroundings, make decisions, track its own position, and operate reproducibly under real-world conditions.

The motivation behind this project is to combine several technical disciplines into a fully functional system. The mouse must be able to detect walls, control its motors precisely, execute motion profiles, collect measurement data for development, and provide an objective means of evaluating its performance. At the same time, the platform should be designed so that individual components can be tested, improved, and subsequently reintegrated into the complete system.

This repository contains all source files required for the development of our Micromouse.

Further information is available at [www.micromouse.at](https://www.micromouse.at).
